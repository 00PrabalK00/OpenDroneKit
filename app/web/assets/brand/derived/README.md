# Derived brand assets

These runtime-sized files are generated from the canonical PNG sources in the
parent `brand` directory. Do not edit them as primary artwork.

- Color-mark derivatives use `mark-color.png`.
- `mark-white-64.png` uses `mark-white.png`.
- `wordmark-white-160.png` preserves the alpha silhouette of
  `wordmark-black.png` and applies the white treatment required by the dark UI.

All resizing uses Lanczos resampling without changing the source aspect ratio.
